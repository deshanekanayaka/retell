# Architecture Decision Records

Append-only. Each ADR records a settled decision: the context that forced it, what was decided,
what was rejected and why, and what it commits us to.

**ADRs are never edited to change a decision.** A new ADR supersedes an old one.

Write an ADR when a decision overrides a previous one, closes a debated choice, or gets asked
"why is it like this" a second time.

Drafting: AI may draft, Deshan approves and flips Status from Proposed to Accepted. Template:
`_TEMPLATE.md`.
